# Akane 实际引擎重测

本轮已于 2026-09-06 完成：四组、十二个独立存储探针均交付并保存终答，逐题语义评分为 **11/12**。详见 [完整报告](actual_experiment_report.md)、[结果数据](actual_results.json) 与 [本地完整调用轨迹](../../../.research-runs/akane-retest-live-20260906-attempt02/TRACE_INDEX.md)。这是每条件一次的探索性预实验，不是一般成功率估计。

本轮直接运行 Akane 的 `AkaneMemoryEngine.process_turn`，用于替代首轮受限宿主对 Akane 行为的推断。首轮原始轨迹、失败和费用保留在 `pilot_v1` 及对应本地研究产物中，不用重测覆盖。

同一场景的 full/card 两条件只主动切换 `operation_projection_policy`；养成关闭，使用原始角色模板、原生工具规格、工具循环及终答验证与恢复。每组的三个探针使用独立物理存储重放相同准备历史，重放不调用付费 API。每次实际 HTTP 请求，包括宿主恢复调用，都继续使用原有阶段账本，阶段累计上限为 50 元。

真实 Akane 会在卡片策略下自动加入稳定的回读说明；两条件的系统提示因此并非逐字相同。本轮比较的是宿主中该配置的完整行为，包括卡片投影及其配套提示，不能解释为单独改变存储投影的因果消融。

场景正文与评分标准沿用首轮。时间输入改用实际调用时刻，以匹配真实引擎使用墙上时钟写入助手消息的行为。因此本轮的间隔是脚本中的对话轮次，不声称模拟了一天的真实经过时间。原场景时间保留为脚本来源信息。

正式调用前须通过 `host_equivalence_checklist.md` 中的离线宿主验收。结果中分别记录宿主验收、传输完成、回答正确性、回读证据和外部中断；这些状态不能互相替代。

`run_manifest.json`、`scenarios.json` 与 `answer_key.json` 保留执行前冻结版本，包括准备状态字段；运行是否完成以原始执行报告及本目录结果文件为准。测试用的离线账本数值不计入费用。本次新增 48 次真实模型请求，时段费率估算 0.1047375 元；含此前请求的整个第一阶段按峰值费率保守预算记账 0.5425634 元，未决预留为零。供应商账单金额未取得。
